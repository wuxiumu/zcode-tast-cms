# 06 前端设计

## 1. 工程结构

```
frontend/
├── h5/       # 用户端（移动优先，手机浏览器/微信内打开）
│   ├── vite.config.ts        # proxy → 后端 /api
│   └── src/
│       ├── api/              # 接口封装（按 04 文档分模块）
│       ├── pages/            # 页面（见 §3）
│       ├── components/       # 通用组件（见 §5）
│       ├── stores/           # zustand：auth、user
│       └── router.tsx
└── admin/    # 管理端（PC）
    └── src/                  # 同构，pages/components 换成 admin 内容
```

技术栈统一：React 18 + Vite + TypeScript + react-router v6 + @tanstack/react-query + zustand（仅存 token/user）+ axios。

请求封装要点：
- axios 拦截器：自动带 `Authorization`；`code===1002` 清 token 跳登录；`code!==0` 统一 Toast 错误消息（除非调用方声明自行处理）。
- react-query keys 约定：`['categories']`、`['materials', cid, tag, page]`、`['task', taskId]`；领取/提交成功后 `invalidate` 相关 key。

## 2. H5 页面清单与路由

| 路由 | 页面 | 内容 |
|------|------|------|
| `/login` | 登录 | 手机号+验证码；登录后跳转来源页 |
| `/` | 首页 | 一级分类宫格（游戏/影视/…），点进二级分类 |
| `/c/:categoryId` | 任务大厅 ⭐ | 二级分类标题 + 标签筛选 tab（全部/小红书/视频号/…）+ 素材卡片列表（无限滚动） |
| `/m/:materialId` | 素材详情 | 封面/图片轮播或视频播放、文案（一键复制）、注意事项、奖励说明、领取按钮 |
| `/tasks` | 我的任务 | 状态 tab：待发布 / 待审核 / 可补数据 / 已完成 / 已过期 |
| `/tasks/:taskId` | 任务详情 ⭐ | 状态进度条、素材内容入口、按状态渲染操作区、奖励明细 |
| `/rewards` | 奖励记录 | 流水列表（金额、来源任务、类型、状态） |

### 2.1 任务大厅（核心页）

```
┌──────────────────────────────┐
│ ‹ 游戏 / 蛋仔派对              │
│ ┌────┬────┬────┬────┐        │
│ │全部│小红书│视频号│抖音│ …     │  ← 标签 tab（3.4 接口）
│ └────┴────┴────┴────┘        │
│ ☑ ┌────┐ 蛋仔夏日皮肤   ￥3.00  │
│   │封面│ 首奖3.00  剩37份    │  ← 卡片：封面/标题/首奖/剩余配额
│ ☑ ┌────┘ 已领过 / 线条置灰     │
│   │封面│ ...                 │
│ ──────────────────────────   │
│ 已选 2 个     [ 领取所选任务 ] │  ← 底部浮动条，勾选≥1 才可点
└──────────────────────────────┘
```

- 卡片左上角 checkbox 支持多选（「选择 1,2,3 发布」）；已领取的卡片显示「查看任务」角标且不可再勾选。
- 点「领取所选」→ 调 3.7 → 成功后弹「领取成功，去发布」引导，跳第一个任务详情；部分失败（理论上整体回滚，兜底展示失败明细）。

### 2.2 素材详情

- 文案块：`text` 全文 + 「复制」按钮（navigator.clipboard）。
- 图文：图片纵向排列，长按/按钮保存（提供单图放大预览 antd-mobile ImageViewer）。
- 视频：`<video>` 播放 + 「保存视频」提示（浏览器限制时引导用链接）。
- 奖励区：首奖金额 + 数据档位表（播放≥1000奖1元…）+ 「领取任务」按钮（未领取时）；已领取则跳自己的任务详情。

### 2.3 任务详情（按状态渲染操作区）

| 任务状态 | 操作区 |
|----------|--------|
| claimed（待发布） | 发布引导（标签 guide 文案）+ 素材内容 + 「我已发布，提交凭证」→ 表单（链接输入 + 截图上传≤3张）→ 3.10；底部倒计时（deadline） |
| submitted（待审核） | 展示已提交内容 + 「审核中，预计24h内」 |
| claimed 被驳回回落 | 顶部红条展示驳回原因，重新提交 |
| bonus_open（可补数据） | 已得奖励、规则档位表、当前轮次/上限、「数据达标了？补发截图」→ 表单（自报数据+截图）→ 3.11 |
| bonus_pending | 「数据审核中」 |
| finished | 累计奖励 + 明细 |
| expired | 「已过期」灰态，重新领取入口 |

上传组件：压缩到 ≤2MB/张（canvas 重绘）再传，减少流量与失败率。

| 路由 | 页面 | 内容 |
|------|------|------|

## 4. 素材编辑表单（Admin 核心页）

分区块（Steps 或 Anchors）：

1. **基本信息**：标题、类型（Radio：图文 / 视频+文字）、二级分类（级联选择）。
2. **内容**：
   - 图文 → 多图上传（拖拽排序，1~9 张，第一张默认封面）、文案 textarea。
   - 视频 → 视频上传（进度条、≤200MB）、封面图、文案 textarea。
   - 发布说明 textarea（md 正文，展示给用户的注意事项）。
3. **标签（预留位）**：标签多选 Select，按 type 分组展示（当前=渠道组）；≥1 个必选。
4. **奖励规则**：首奖金额；数据规则动态行编辑器（指标 Select + 阈值 InputNumber + 奖励金额；增删行）；叠加模式 Radio（取最高/叠加）；补发轮次上限（0=关闭）。
5. **发布配置**：配额（-1 不限）、每人限领、提交时限（小时）。
6. **操作**：保存草稿 / 保存并上架；published 状态修改奖励规则弹二次确认。

## 6. 视觉规范（从简）

- 主色：H5 用橙黄系（激励感），Admin 用 AntD 默认蓝；语义色：成功=绿、待审=橙、驳回/过期=红。
- 金额统一突出展示（加粗放大）；所有奖励数字保留两位小数。
- H5 页宽 `max-width: 480px` 居中，兼容微信内置浏览器（X5 内核，避免用 `gap` 于 flex 旧写法等）。

## 7. 构建与联调

- dev：Vite `server.proxy` 将 `/api`、`/uploads` 代理到 `http://127.0.0.1:8080`（PHP 内置服务或 nginx）。
- build：产物分别输出 `h5-dist/`、`admin-dist/`，由 Nginx 托管（02 文档 §5）。
