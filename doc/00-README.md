## 核心概念速查

- **分类（Category）**：两级结构，如 `游戏 > 蛋仔派对`、`影视 > 斗破苍穹`。
- **标签（Tag）**：当前主要为「渠道」标签，如 `小红书`、`视频号`、`抖音`；素材上预留多标签位。
- **素材（Material）**：图文（多图+文案）或 视频+文字；后台录入，配置奖励规则与配额。
- **任务（Task）**：用户领取某素材后生成的实例，跟随用户走完整生命周期（发布→提交→审核→奖励→数据补发）。
- **凭证（Submission）**：首发凭证（链接+截图）与数据补发凭证（数据截图）两类，人工审核。
