# 09 代码执行计划（MVP）

> 目标：按 01~08 文档快速落地一个可跑通全流程的 MVP，代码保持 Store/Service 分层，为后续优化留好替换点。

## 1. 环境结论（2026-10-01 实测）

| 项 | 结果 | 影响 |
|----|------|------|
| PHP 8.3.26 + **phpredis 扩展** | ✅ | 后端**零 composer 依赖**：路由/JWT/自动加载自写，Redis 用原生扩展 |
| Redis 7（本机已运行） | ✅ | 直接可用 |
| Node | 系统 node 是 v12 且 npm 损坏；nvm 有 v22.22.0 + npm 10.9.4 | 前端统一用 `~/.nvm/versions/node/v22.22.0/bin` |
| 网络 | npm registry / packagist 连通 | 前端可 npm install；后端无需安装 |

## 2. MVP 相对设计文档的裁剪与偏差

| # | 裁剪/偏差 | 原因 | 恢复方式 |
|---|-----------|------|----------|
| 1 | frontmatter 用 **JSON** 而非 YAML | 零依赖、读写同源、人工仍可编辑 | 换 symfony/yaml 只动 FileStore |
| 2 | 短信验证码 mock：固定 `123456`（config 可改） | 无短信服务商 | 接入通道只动 AuthService |
| 3 | 管理员账号写死 `config/admin.php`（admin/admin123） | 管理员≤3人 | 后续建 admin 表 |
| 4 | 通知红点/看板明细从简：只做 overview 计数 | 优先闭环 | NotifyService 预留位在 |
| 5 | 限流保留：登录 5/分、提交 10/日、领取 20/日（Redis 计数） | 成本低防薅 | - |
| 6 | H5 截图压缩不做，服务端限 10MB/张 | 先跑通 | 加 canvas 压缩组件 |
| 7 | per_user_limit 语义按 1 实现（>1 预留字段） | 业务默认 1 | 改 claim Lua 计数键 |

## 3. 后端实现要点（对应 05 文档键名）

- 路由：`public/index.php` 单入口，路由表 + `{param}` 匹配 + auth 分组（public/user/admin）。
- 金额：**统一以「分」存整数**（Redis 与 API 内部），接口出入参用两位小数字符串。
- 领取：Lua 原子（配额/唯一/建任务/扣减/进 deadline zset），多选失败整体补偿回滚。
- 凭证冗余 `reward_snapshot`（提交时刻奖励规则），审核按快照核算。
- 去重：首发链接 sha1 全局唯一；截图 md5 30 天去重。
- 过期：读取时惰性判断 + `scripts/expire-sweep.php` 每 5 分钟兜底。
- 索引：素材上架同步 Redis zset 索引与 meta 缓存；`scripts/rebuild-index.php` 可全量重建。
- 开发服务器：`php -S 0.0.0.0:8080 -t backend/public backend/public/index.php`（入口同时托管 /uploads 静态文件）。

## 4. 前端实现要点

- `frontend/h5`：Vite5 + React18 + TS + antd-mobile v5 + react-router v6；页面：登录/首页分类/任务大厅(多选领取)/素材详情/我的任务/任务详情(状态分区操作)/奖励记录。
- `frontend/admin`：Vite5 + React18 + TS + antd v5；页面：登录/看板/素材列表/素材编辑(类型切换+标签多选+奖励规则行编辑)/分类与标签/审核中心(首发+数据两个tab+抽屉)/奖励记录(标记打款)。
- dev 代理：vite server.proxy 将 `/api`、`/uploads` → `http://127.0.0.1:8080`。
- 状态：token 存 localStorage；请求用轻封装 fetch（不引 axios/react-query，减少依赖面）。

## 5. 执行顺序与验收

| 步 | 内容 | 验收 |
|----|------|------|
| 1 | 后端骨架（入口/配置/Resp/Http/Jwt/RedisStore/FileStore） | `curl /api/v1/ping` 返回 0 |
| 2 | 分类/标签/素材服务 + 上传 + 管理端控制器 | 建分类→标签→素材→上架→用户端列表可见 |
| 3 | 用户/任务/奖励服务（Lua 领取、提交、审核、补数据） | 状态机全流转正确 |
| 4 | 种子数据 + `scripts/smoke.php` 全流程冒烟 | 脚本输出 ALL PASS |
| 5 | H5 前端 7 页 | `npm run build` 通过 + 联调 |
| 6 | Admin 前端 | `npm run build` 通过 + 联调 |
| 7 | README 启动说明 + 裁剪清单回填 | - |

## 6. 本地启动（交付后日常）

```bash
# 后端（Redis 需已运行）
php -S 0.0.0.0:8080 -t backend/public backend/public/index.php
# H5
export PATH=~/.nvm/versions/node/v22.22.0/bin:$PATH
cd frontend/h5 && npm install && npm run dev      # http://localhost:5173
# Admin
cd frontend/admin && npm install && npm run dev   # http://localhost:5174
# 账号：管理端 admin/admin123；用户端手机号任意 + 验证码 123456
```
